## Findings & resolutions

1. **[Low] `board:deleted` has no producer** — the client redirect handler exists and is
   unit-tested, but no action emits the event (board delete = soft archive today). Left as-is;
   a future permanent-delete action should emit it.
2. **[Info] F2×U5 interplay** — after a revocation kick, socket.io-client does not auto-reconnect
   (`skipReconnect`), so the tab froze until reload. Resolved in round 2 (A3): one manual
   reconnect per kick; the server re-authorizes every re-join, a revoked user is denied again
   and surfaced via `board:error` → `router.refresh()`.
3. **[Info] F4 sheet residual** — sheet labels were server-prop driven. Resolved in round 2 (A1).
4. **[F9, evaluated — NOT changed]** CardReminder claim-first dedup: a process crash between the
   claim insert and the notification send leaves the claim row, so that reminder is never
   retried. Keeping claim-first (idempotency under overlapping ticks/dual drivers is the
   property that matters); a safe fix would require two-phase semantics and is out of scope.
   Documented here as a known limitation.

### A3 security assessment (reconnect-once)

- **(a) No stale room restore:** rooms are joined only inside `board:join`/`workspace:join`
  after per-room authorization (`getBoardMembershipRole` / `canUserJoinWorkspace`); the only
  unconditional join is the user's own `user:{id}` notifications room. A fresh socket has no
  board/workspace rooms until providers re-emit joins and the server re-authorizes them.
- **(b) No broadcast leak between reconnect and refresh:** the reconnected socket is in no
  board/workspace room, so it receives nothing but its own user-room notifications until a
  join completes.
- **(c) No reconnect loop:** `shouldReconnectOnce` allows at most one retry per
  server-initiated disconnect; the guard resets only on a successful connect, and
  `socket.connect()` is a no-op while connected. A server that keeps kicking yields one retry
  per kick, never an unbounded loop. Client-initiated disconnects (logout/unmount) never
  trigger the retry.
